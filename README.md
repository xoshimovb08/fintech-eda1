# 🏦 Fintech-EDA

O'zbekiston Moliya Sektori Monitoring - AML Alert Escalation Prediction

## 🎯 Maqsad

Avtomatlashtirilgan AML ogohlantirishlarining kuchaytirilish ehtimolini 
bashorat qilish uchun machine learning modeli.

## 📊 Model

- **Algorithm:** LightGBM Classification
- **Features:** 19 aggregated features
- **ROC-AUC:** 0.5904
- **Dataset:** 14,000 training signals + 7M transactions

streamlit run streamlit_app.py
